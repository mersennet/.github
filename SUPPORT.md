# Support

- **Using Mersennet** (wallet, faucet, trading, staking): [docs.mersennet.com](https://docs.mersennet.com) first, then the [Telegram group](https://t.me/Mersennet).
- **Running a node**: [Run a node](https://docs.mersennet.com/validators/run-a-node/) and [Become a validator](https://docs.mersennet.com/validators/become-a-validator/); operators can enable Telegram alerts for their node from the staking page.
- **Bugs**: open an issue in the matching repository (templates guide you).
- **Security**: security@mersennet.com — never a public issue.
- **Status**: [status.mersennet.com](https://status.mersennet.com/status/mersennet).
