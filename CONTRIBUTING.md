# Contributing to Mersennet

Thanks for helping. This file applies to every Mersennet repository that does
not have its own CONTRIBUTING.md.

- **Branches**: `develop` is the integration branch, `main` is what is deployed. Open pull requests against `develop`.
- **Commits**: small and described in the imperative ("add", "fix"); one topic per PR.
- **Tests**: run the repository's test command before pushing; CI runs it again on the PR.
- **Style**: follow what is around you — the repos are consistent on purpose.
- **License**: the SDKs, explorer, website and faucet are MIT. The node is source-available under the Business Source License 1.1 and needs the CLA in its repository.
- **Security**: never in a public issue — security@mersennet.com.
