# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, no harassment, no discrimination.
Reports: conduct@mersennet.com (or any admin in the Telegram group). Maintainers
may remove, edit or reject contributions and comments that break this, and ban
repeat offenders.
